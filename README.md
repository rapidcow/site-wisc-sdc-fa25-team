# Team 17 Wiki Deployment

This is a read-only deployment of [eyzmeng/site-wisc-sdc-fa25-team](https://github.com/eyzmeng/site-wisc-sdc-fa25-team)!
It will be made accessible on the Web at <https://rapidcow.github.io/site-wisc-sdc-fa25-team/>.
There is a GitHub webhook that logs your pushes, and I will merge
according to the logs from the webhook.  Currently the process is
*not* automatic, but considering that most of the time I am the
one editing, I don't see an immediate need to teach the webhook
about how to perform these merges.  If you think this is an issue,
help me with [improving the Webhook](https://github.com/rapidcow/site-wisc-sdc-fa25-team/tree/mod/cgi-bin)!
